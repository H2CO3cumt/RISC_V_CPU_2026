## 4. 字幕规范

- 一行 ≤16 汉字，最多两行；**所有数字上字幕**。
- 字幕 ≠ 逐字稿：旁白讲因果，字幕放证据（数值、命令、判据、文件名）。
- 口播取整、字幕精确：口播"零点六"，字幕写 `0.597`。
- 录屏前把上位机与终端字号放大到 **150–200%**，录 **1920×1080**（不要录 4K 再压）。
- 窗口提前摆好、鼠标不乱晃、通知全关——你没有实拍特写，画面清晰度就是全部。

## 5. 数字红线

1. 每个数字必须能在 `release/evidence/claims_map.md` 查到；查不到**不许上字幕**。
2. 资源/时序只挂 85 MHz 交付位流 `C017ED10…`：**4995 LUT / 3907 FF / 6.0 DRM18K / APM 4 / WNS +0.577 / 估算 Fmax 89.3841 MHz**。
   （旧稿的 `3908 FF` 是笔误，正确是 **3907**。）
3. CoreMark 分数来自**计分位流**，与交付位流不是同一颗 → 字幕必须分行标位流。
4. 演示用的 `tr85` 是**附加演示位流**：它的 LUT/DRM **不得当交付面积**；板级 `100/100` 验收是在 `la85` 上做的。
5. **没有实拍的不许写成拍到了**：LED、跳线、手部动作都没有素材。
6. 不许上屏：板上 95 MHz、LA 能跑 90 MHz、把 PDS 估算 Fmax 说成"实测"、DDR3 吞吐/延迟、Cache 的 Off/On 净收益、Trap↔return 的"5 样本"当 5 周期、三位以上 CPI。
7. 作废数字一个都不许再用：`3550 LUT / Fmax 58.1801 / Score 45.051`、`72.081 / 901`、`1.5388`、`4479 LUT / 89.4721 MHz`、`89.2538 MHz`、`3908 FF`。

## 6. 开录前检查

```powershell
# 1) 预检（只读、不下载、不占串口）
& "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -ExecutionPolicy Bypass -File scripts\demo_preflight.ps1 -Port COM11
# 预期： DEMO PREFLIGHT PASS warnings=0

# 2) 段二要用 tr85，先冒烟一次 mirror（这一枪决定全片金句成不成）
& "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -ExecutionPolicy Bypass -File scripts\program_board.ps1 -Config tr85
python python\logic_analyzer_serial.py COM11 --mode mirror --text "HELLO,RISC-V" --runs 1
```

- `preflight` 的 `$bitstreams` **不含 tr85**，所以它 PASS 不代表 tr85 对；拍前单独 `Get-FileHash` 核一次。
- 串口纪律：`uart_rx` 没有 FIFO，**必须等 `TRACE_ARMED` / `LA_READY` 再发下一个字节**，手动敲串口助手一定会被吞命令。
- 别用 `-Oneshot`（交付固件没有 `0xA6`）；触发条件永不出现会把固件停住，只能按 REST 或重下位流。
- 拍完恢复：`scripts\program_board.ps1 -Config la85`。
